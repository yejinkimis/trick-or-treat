# 똑똑 할로윈

픽셀 마을을 돌아다니며 친구 집 문을 두드리고 사탕을 주고받는 할로윈 게임. 코스튬, 호박 바구니, 타이밍 노크, 장난(trick), 뿅망치, 방명록, 집 꾸미기, 지붕 그림, 채팅이 있다.

## 혼자 돌려 보기

`prototype/trick-or-treat.html`을 브라우저로 열면 연습 모드로 뜬다. 가짜 친구 두 집과 돌아다니는 봇(테스트친구)이 있고, 기록은 새로고침하면 사라진다.

## 실제 게임은 어디서 도나

친구들과 함께 하는 버전은 claude.ai 아티팩트로 올라가 있다. 저장(db), 접속자(user), 실시간 위치·채팅(room)은 아티팩트가 주는 `window.claude` 런타임을 쓴다. 그래서 이 HTML을 다른 곳에 그냥 올리면 연습 모드로만 돈다.

아티팩트에 다시 게시하는 건 코코가 한다. 고친 내용은 브랜치를 따서 PR로 올리면 머지 뒤 게시한다.

## 고칠 때

- 파일은 HTML 하나다. CSS, 스프라이트, 게임 로직이 모두 들어 있다.
- 스프라이트는 문자 격자와 팔레트로 그린다. 새 코스튬은 기존 스프라이트를 따라 하면 된다.
- 규칙 숫자(시작 사탕, 장난 시간, 기절 횟수 등)는 스크립트 위쪽 상수에 모여 있다.
- 사탕 개수는 저장하지 않고, 모두의 노크 기록을 시간순으로 다시 계산해서 낸다. 판정이 브라우저에서 나서 마음먹으면 조작할 수 있다.
